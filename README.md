# KernelSU Waydroid

KernelSU for Waydroid — built from [supechicken/KernelSU](https://github.com/supechicken/KernelSU/tree/waydroid) with automated manager build workflow.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/Yuu-DevID/KSU-Waydroid/refs/heads/waydroid/install.sh | sudo bash
```

## Load KernelSU

```bash
sudo load-ksu
```

## Manager APK

Download the latest manager APK from [Releases](https://github.com/Yuu-DevID/KSU-Waydroid/releases).
